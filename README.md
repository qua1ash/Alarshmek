# Alarshmek

Минималистичный будильник для Android. Текущий этап: добавление, включение/выключение и удаление будильников.

## Запуск

1. Откройте папку проекта в Android Studio (Ladybug или новее).
2. Дождитесь окончания Gradle Sync.
3. Выберите эмулятор либо подключённый Android-телефон (Android 8.0+).
4. Нажмите `Run`.

Проект использует Kotlin и Jetpack Compose и не содержит нативных `.so`-библиотек: одна сборка подходит для ARM/ARM64 и x86/x86_64.
